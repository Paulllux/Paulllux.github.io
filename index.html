BeatForge - Drum Machine & Sequencer Plugin

BeatForge is a powerful JUCE-based audio plugin for creating drum patterns, sequencing, and sound design. It supports sample loading, synthesis, multi-track sequencing, effects, LFO modulation, and more. Available as a VST3/AU plugin for Mac and Windows.

User Manual

This manual is based on a thorough analysis of the plugin's source code. BeatForge is a multi-track drum sequencer with advanced features for sound manipulation and performance.

1. Overview

BeatForge allows up to 64 tracks, each with a 16-step sequencer per bar. Supports multiple bars (up to configurable total). Modes include Sample (load audio files) and Synth (oscillator-based synthesis). Global FX bus for reverb or external routing. MIDI I/O support for external control/triggering.

2. Installation

  • Download the plugin from the link above.
  • Extract the ZIP and place the .vst3/.component file in your DAW's plugin folder (e.g., ~/Library/Audio/Plug-Ins/Components/ on macOS).
  • Scan for plugins in your DAW (e.g., Ableton, Logic, etc.).
  • On first launch, you'll see a trial/activation screen. Start a 14-day trial or activate with email/code.

3. Interface Layout

The main window is divided into:

  • Top Controls: Add Track, Track Selector Combo, Song Menu (Save/Load/New), FX Mode (External/Internal Reverb), Song Choice Combo.
  • Bar Controls: Total Bars (+/-), Current Bar (+/-), Copy/Paste Bar.
  • Tab Buttons: Mix, Time, ADSR, FX (Pitch/Dist/BitCrush), EQ, LFO, Synth - switches all tracks to the selected tab view.
  • Track List: Scrollable list of tracks with labels, sample choice, solo/mute, 16-step buttons, and tabbed controls.
  • Status Labels: Version, Sample Rate, Trial/Activation Status.

4. Track Management

  • Add Track: Click "Add Track" to create a new track (up to 64).
  • Select Track: Use the combo box or click track label (Cmd+Click for multi-select).
  • Delete Track: Right-click track label > Track Operations > Delete Track.
  • Track Label: Editable name. Right-click for context menu (outputs, MIDI, modes, etc.).
  • Solo/Mute: Toggle buttons. Solo overrides mute.
  • Sample Choice: Combo for loading samples. "Load Sample..." opens file chooser. Supports WAV/MP3/AIFF. Drag-drop files onto tracks.
  • Random Sample Mode: Right-click label > Random Sample Mode. Loads random samples from folder on trigger.
  • Mode Switching: Right-click label > Mode > Sample/Synth. Sample: audio files; Synth: oscillator-based (Sine/Saw/Triangle/Square/Noise).

5. Sequencer

  • Steps: 16 toggle buttons per bar. Click to enable/disable hits.
  • Right-Click Step: Menu for Chance (5-100%), Group (1-32 for parameter groups), Group Settings (Copy/Paste), Roll (1-16 flam/rolls).
  • Hit Chance: Probability of trigger (visualized on button LED: magenta if <100%).
  • Edit Groups: Assign steps to groups (1-32) for per-group params (volume, pitch, etc.). Current group highlighted.
  • Roll/Flam: Set divisions (1-16) for rapid repeats. Visualized as pie slices on button LED.
  • Multi-Select Steps: Cmd+Click to select multiple; apply changes to all.
  • Bar Navigation: Change total/current bars. Copy/Paste bars (single track or all).
  • Playback: Syncs to host transport. Flashing highlights current step.

6. Tabbed Controls (Per-Track, Synced Globally)

Click tab buttons to switch views for all tracks.

  • Mix: Volume (-60 to +12 dB), Pan (L/R), FX Send (-112 to +12 dB), Phase Invert (toggle).
  • Time: Swing (50-75%), Nudge (-50 to +50 ms offset), Reverse (toggle + Trim 0-16 steps).
  • ADSR: Attack (0-0.02 s), Decay (0.01-1000 ms), Sustain (0-1), Release (1-2000 ms).
  • FX: Pitch (-12 to +12 semitones), Distortion (0-30 dB drive; right-click for types: Soft/Hard/Foldback/Hardcore), BitCrush (2-16 bits; "Off" at 16).
  • EQ: HP (toggle + 20-20k Hz cutoff), LP (toggle + 20-20k Hz cutoff).
  • LFO (3x): Enable (toggle), Freq (0.1-20 Hz or Per Beat; right-click for mode/type/targets), Amp (0-100%). Right-click Freq: Mode (Hz/Per Beat), Type (Sine/Square/Saw/Triangle/Noise), Targets (multi-select: Audio/Volume/Pan/Pitch/Dist/FX Send/HP/LP/Attack/Decay/Sustain/Release).
  • Synth: Base Freq (20-100 Hz), Osc Type (combo: Sine/Saw/Triangle/Square/Noise), Pitch Drop (0-48 semitones), Drop Rate (1-2000 ms), KeyTrack (toggle MIDI note tracking).

Note: Params are per-edit-group. Changes apply to current group.

7. Global Features

  • Song Management: Save/Save As/Load/New. Songs stored as .drsong files (JSON-like with params/samples).
  • FX Mode: External Output (select bus) or Internal Reverb (load IR WAV/AIFF, return level 0-1).
  • Mute Groups: Right-click label > Mute Group (1-8 or None). Triggers mute others in group.
  • MIDI: Right-click label > MIDI > Note (None or 0-127), Channel (None or 1-16), Direction (Input/Output), Synth Roll Mode (toggle for sustained synth notes).
  • Outputs: Right-click label > Output Settings > Main/Aux buses.

8. Advanced Usage

  • Multi-Track Select: Cmd+Click labels. Changes apply to all (e.g., step toggles).
  • Clear Hit Chances: Right-click label > Bar Operations > Clear Hit Chances.
  • Synth Mode: No sample needed. Triggers oscillators with ADSR/Pitch Drop/KeyTrack.
  • BitCrush/Sample Rate: Reduce for lo-fi effects. Precomputed for performance.
  • LFO Targets: Modulate multiple params. White Noise for random modulation.
  • Reverb IR: Load custom impulse responses for internal FX.

9. Troubleshooting

  • No Sound: Check mute/solo, output bus, sample loaded, host playing.
  • Trial Expired: Purchase/activate via email/code.
  • High CPU: Reduce tracks/bars, disable unused LFOs/FX.
