User Manual

This guide covers installation, interface, and features to help you get started with BeatForge's intuitive design.

1. Overview

Up to 64 tracks with 16-step sequencing per bar, supporting multiple bars. Modes for samples or synthesis, plus global FX and MIDI I/O.

2. Installation

  • Download the plugin from above.
  • Mac: Use the .pkg installer.
  • Windows: Place VST3 in C:\Program Files\Common Files\VST3\.
  • Scan in your DAW and launch for trial or activation.

3. Interface Layout

Top controls for tracks and songs, bar navigation, global tabs (Mix, Time, ADSR, FX, EQ, LFO, Synth), scrollable track list, and status indicators.

4. Track Management

  • Add tracks (up to 64).
  • Select via combo or click (Cmd+Click for multi).
  • Edit labels, solo/mute, load samples, or switch to Synth mode.
  • Random Sample Mode for variety.

5. Sequencer

  • 16 steps per bar; right-click for Chance, Groups, Rolls.
  • Multi-select steps; copy/paste bars.
  • Syncs to host transport.

6. Tabbed Controls (Per-Track)

Params apply per edit group for precision.

  • Mix: Volume, Pan, FX Send, Phase Invert.
  • Time: Swing, Nudge, Reverse.
  • ADSR: Attack, Decay, Sustain, Release.
  • FX: Pitch, Distortion (types), BitCrush.
  • EQ: HP/LP filters.
  • LFO (3x): Freq, Amp, Types, Targets.
  • Synth: Base Freq, Osc Type, Pitch Drop, KeyTrack.

7. Global Features

  • Song save/load as .drsong files.
  • FX Mode: Internal Reverb or external.
  • Mute Groups; MIDI Note/Channel.
  • Output routing.

8. Advanced Usage

  • Multi-track edits; Clear Chances.
  • Synth Roll Mode for sustained notes.
  • LFO for random modulation; Custom IRs.

9. Troubleshooting

  • No sound: Check mutes, samples, playback.
  • Trial: Activate via email/code.
  • CPU: Optimize tracks/LFOs.
